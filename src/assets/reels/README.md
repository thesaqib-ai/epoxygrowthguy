# Reel thumbnails

Drop vertical 9:16 thumbnails here, for example `christopher-land.jpg`, then
point the matching entry in `featuredReels` in `src/data/guests.ts` at the file
name.

Aim for 720x1280. Astro optimizes them at build time.

There is no Instagram embed script anywhere on this site. The cards are local
images that link out to the reel, which keeps the page fast.
